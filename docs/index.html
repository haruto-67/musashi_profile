DRUMS / PERCUSSION

相川 涼太

RYOTA AIKAWA

叩くことを仕事にして9年。4組のバンドにメンバーとして在籍していて、サポートは年に10本ほど。月に7本くらい、どこかの箱にいます。速い曲も遅い曲もやりますが、ハネる曲をいちばん長くやってきました。

活動地域
東京・神奈川を中心に関東近郊。関西・東海への遠征も相談できます。
報酬の目安
ライブサポート 1本 20,000円〜（リハ別・交通費別）／レコーディング 1曲 15,000円〜。本数や内容によって相談可。
日程について
月7本ほど稼働。空きは下のカレンダーのとおりです。3週間前までにご相談いただけると動きやすいです。
機材
Yamaha Recording Custom / Zildjian K。スネアとシンバルは持ち込み、現場に合わせて変えます。
